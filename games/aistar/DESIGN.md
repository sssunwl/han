# AI 明星養成 — 設計文件

> 一句話:你開了一間 **AI 時代的媒體公司**,旗下是一群 AI 明星。每位明星都有自己的性格,像真人一樣會**搶角色、搶活動、搶劇本**。你決定給誰,沒被選上的人會照自己的個性反應。

- 對象:小學中高年級。一隻手指能玩,手機直式和電腦都可以。
- 全部離線,**不呼叫任何 AI API**。「像真人」是靠性格系統 + 大量對話模板組出來的。
- 美術全部用 `shared/pixelkit/`(程式畫的):人物是 `character.js` 的 Q 版小人,場景在新檔 `studio.js`。
- 內容規範:競爭是良性的(比誰練得好、誰比較適合),**沒有感情緋聞、沒有霸凌、沒有成人內容**。「吃醋」是吃「被選上的機會」的醋,不是感情。

---

## 1. 一週的流程(回合制)

一回合 = 一週。回合制比即時好:小孩可以慢慢看每個明星講什麼、慢慢想要給誰。

```
週一 早上          白天(玩家操作)                     週日 晚上
┌──────────┐   ┌─────────────────────────────┐   ┌──────────────┐
│ 趨勢快報   │ → │ 📋 機會板:新角色/活動/劇本開出來 │ → │ 週報:          │
│ 演算法變了 │   │    有興趣的明星跑來搶(對話泡泡)  │   │ 演出評價 S~C   │
│ 下週預告   │   │    → 你選一位,其他人當場反應     │   │ 粉絲、收入     │
│ 突發事件   │   │ ⭐ 沒接案的人:排練習/休息/自己直播 │   │ 誰鬧彆扭、誰變朋友│
└──────────┘   └─────────────────────────────┘   └──────────────┘
```

按「▶ 下一週」結算。沒人接的機會一週後會被別家公司接走。

|---|---|---|---|---|

| 🎬 AI 短劇 | 星劇場 | 🎭演技 | 2 | **分主角/配角**,最常吵著要主角 |
| 🔴 直播 | 直播島 | 🎙口才 | 1 | 收入看粉絲數 |
| 🎧 Podcast | 耳朵電台 | 🎙口才 | 1 | 穩定,害羞的人也敢接 |
| 🎤 虛擬演唱會 | 元宇宙舞台 | 🎤歌唱 + 💃舞蹈 | 3 | 公司 Lv3 解鎖,大場面 |
| 🎮 遊戲代言 | — | 魅力(粉絲) | 1 | 錢多、粉絲少 |
| 📺 廣告 | — | 全部平均 | 1 | 錢多 |
| 🏆 選秀節目 | 星光擂台 | 看題目 | 2 | 跟別家明星比,名次決定獎勵 |
| 🎙 AI 繪本配音 | 故事盒子 | 🎙口才 + 🎭演技 | 1 | 偶爾出現 |
| 👯 雙人企劃 | 各平台 | 看題目 | 1~2 | 要兩個人,好朋友一起有加成 |

**趨勢每週會變**(這是「AI 時代」的核心感):
- **演算法**:每週一個媒體被推(收入/粉絲 ×1.5),偶爾「演算法大改版」讓某個媒體降溫兩週。
- **流行話題**:每週一個話題(#恐龍 #太空 #美食 #運動 #下雨天 #復古 #海洋 #魔法……),標了這個話題的機會加成。
- **下週預告**:提前一週公告下週的演算法,所以「這週先練舞、下週接舞蹈」是一個真正的決定。
- **新平台上線**事件:偶爾冒出限時的新媒體(全息直播、AI 寵物頻道……),好奇的明星會搶著去。

## 3. AI 明星

每位明星 = 外觀 + 性格 2 個 + 技能 4 項 + 狀態 + 想要的東西 + 人際關係。

### 外觀
- `randomLook(seed)` 決定膚色/髮型/髮色/衣服顏色(格子 24×32,腳在 y=30;**不改 character.js**)。
- 辨識度靠配色,再加遊戲自己疊的:**頭上小配件**(耳機、皇冠、星星髮夾、眼鏡、帽子、蝴蝶結、AI 天線、光環)和**專屬光效顏色**(腳底光圈、選上時的光芒)。
- 每位有名字、代表 emoji、**口頭禪**(例:「嗶嗶~」「OK 的啦」「衝了!」),講話時會帶上,同一位明星講話風格一致。

### 性格(12 種,每人抽 2 種:主性格決定講話口氣,副性格加料)

| 性格 | 搶資源時 | 被選上 | 沒被選上 |
|---|---|---|---|
| 🔥 好勝 | 大案子一定搶,會點名對手 | 「我就說吧!」 | 不服輸 → **更努力練習**(練習效果 ×1.5 兩週),跟贏家變成對手 |
| 🙈 害羞 | 很少搶,講話小聲「那個…可以讓我試試嗎?」 | 大場面會緊張(有好朋友同場或心情好就不會) | 「沒關係…」心情小降 |
| 💎 完美主義 | 只搶自己最強的項目 | 練過那項技能會加分 | 「是我練得不夠」→ 心願變成「想練某技能」 |
| 😂 愛搞笑 | 愛搶短影音、綜藝 | 讓全公司心情變好 | 笑笑帶過,可能自己拍搞笑影片 |
| 💢 愛吃醋 | 看到別人一直被選會更想要 | 開心一下就忘了 | 心情大降、跟贏家關係變差;連輸 3 次 → **鬧彆扭**一週不練習(要去安慰) |
| ⚡ 熱血 | 什麼都想搶 | 「衝啊!」 | 「我去練習了!」自動加練;體力掉比較快 |
| 🌙 悠哉 | 不太搶 | 「嗯~好喔~」 | 「那我去睡午覺」幾乎不在意;練習慢 |
| 🔍 好奇 | 搶新平台、熱門話題 | 很興奮 | 很快轉移注意力,可能**找別人組隊**自己做企劃 |
| 🌠 夢想家 | 有一個夢想媒體,看到一定搶 | 夢想成真,大爆發 | 夢想的機會沒給他 → 歸屬感大降 |
| 💗 貼心 | 會**讓給更需要的人** | 感謝大家 | 恭喜贏家,關係變好 |
| 👑 愛面子 | 想當主角、討厭配角和小案子 | 很得意 | 心情降、歸屬感降 |
| 🎧 獨行俠 | 討厭雙人企劃 | 冷冷一句「交給我」 | 小降,不太表現 |

### 技能
🎤歌唱、💃舞蹈、🎭演技、🎙口才,0~10。開局每人有一項專長。練習會進步,越高越難練(邊際遞減)。

### 狀態
- **心情** 😄 0~100:影響演出。被選上/休息/心願達成會上升;沒被選上、太累會下降。
- **體力** ⚡ 0~100:接案、練習、直播會累;低於 20 演出打七折而且會抱怨。
- **歸屬感** 💗 0~100:長期被冷落、心願一直沒實現會下降。**低於 25 → 想跳槽事件**:「收到別家公司的邀請」,可以談心、答應他的心願(三週內要做到)、或讓他走(他的粉絲會帶走一部分)。
- **粉絲**:每位明星有自己的粉絲,公司粉絲 = 全部加起來。

### 想要的東西(心願)
每位明星一次一個心願,做到了心情和歸屬感大加:想接某種媒體、想當主角、想休息、想跟某人合作、想要新造型(換衣服顏色,畫面上看得到)、想學某技能、想上熱門話題的案子、想要粉絲見面會……沒做到會慢慢累積不滿。

### 人際關係
每兩位之間一個分數(-100~100):**🤝 好朋友**(≥40)、**⚔️ 對手**(≤-30,良性競爭)、其他普通。
- 開局隨機有 1~2 對好朋友、1~2 對對手。
- 搶同一個機會、一方贏 → 關係變差;一起完成雙人企劃 → 變好。
- 好朋友同場演出 +15%,也會互相安慰。
- 對手同場「良性競爭」+10%,而且**一起成功就會「惺惺相惜」關係大升**(對手變朋友是好故事)。
- 工作室裡會冒出閒聊:好朋友互相打氣、對手互相嗆聲(只嗆實力,例「下次舞蹈比賽我會贏你喔!」)。

## 4. 搶資源(核心)

新機會開出來時,每位**有空**的明星算一個「想要的程度」:

```
興趣 = 技能合不合 + 性格加減(好勝搶大案、害羞怕大案、熱血全搶、悠哉少搶、好奇愛新、
       愛面子要主角、獨行俠不要雙人) + 喜歡的話題 + 夢想媒體 + 心願 + 上次沒搶到的怨念
       + 對手也在搶(好勝/愛吃醋加碼) + 隨機
```

超過門檻就來搶,用訊息講出**最主要的理由**(技能/夢想/對手/話題/上次輸了/想跟朋友一起/心願)。第二個來搶的人會回應第一個人(「Kiki 你上次已經演過主角了吧!」);貼心的人可能說「我讓給 Mimi 好了」。

機會卡上會顯示每位候選人的**預估評價**(S/A/B/C),所以每次都是真正的取捨:

> 給最強的人 → 錢和粉絲最多 / 給一直沒被選的人 → 大家開心、留得住人 / 給弱的人 → 培養新人 / 給夢想的人 → 他會大爆發

選完的瞬間,沒被選上的人當場依性格反應(見上表)。

## 5. 經營

- **每位明星每週做一件事**:接案(機會板)/ 練習某技能 / 休息 / 自己開直播(小錢小粉絲)。
- **收入**:案子酬勞 × 評價倍率 × 趨勢加成。**支出**:每週房租 + 明星薪水(越紅越貴)。
- **公司升級**(Lv1 小工作室 → Lv2 攝影棚 → Lv3 媒體大樓 → Lv4 星光塔):明星名額、每週機會數變多,解鎖大媒體。畫面上的攝影棚會跟著變大、多出新設備。
- **設施**:練習室(練習效果)、休息室(休息回復)、AI 剪輯室(作品酬勞加成),各 3 級。
- **試鏡**:每 4 週(或有空位時)可以辦試鏡,3 位隨機新人來自我介紹,選一位簽約。
- **別家公司**:3 家虛構對手公司也在漲粉絲,有排行榜。

## 6. 目標與結局

階段目標(畫面上一直顯示「下一個目標」):

| # | 目標 | 獎勵 |
|---|---|---|
| 🌱 出道 | 完成第一個案子、公司粉絲 1,000 | 獎金 |
| ⭐ 小有名氣 | 粉絲 10,000、公司 Lv2 | 獎金 + 試鏡 |
| 🌟 人氣公司 | 排行榜前 2 名、公司 Lv3 | 獎金 |
| 🏟 星光巨蛋 | 粉絲 100,000、公司 Lv4 → 解鎖「星光巨蛋虛擬演唱會」 | — |
| 🏆 結局 | 巨蛋演唱會(要 3 位明星一起)評價 A 以上 | 結局畫面 |

**結局會依照你怎麼經營而不同**:
- 🤝 **大家庭結局**:大家感情都很好,沒有人離開。
- ⚔️ **宿敵變戰友結局**:有一對對手後來變成好朋友。
- 👑 **超級巨星結局**:有一位明星的粉絲佔全公司一半以上。
- 🌈 **全能公司結局**:每一種媒體都拿過 A 以上。
- ✨ **星光結局**(一般)。

結局畫面:全員站上舞台、每位明星一句感言(照他的性格)、這一季的紀錄(第幾週、粉絲、最高評價、誰變成好朋友)。

**二周目(第二季)**:保留獎盃牆;從這季選 **1 位明星留下當「前輩」**(不搶資源、教後輩練習加成);新人陣容、性格、趨勢全部重新隨機;別家公司變強。

## 7. 重玩性(針對「每次都一樣」的回饋)

每一局都不一樣的東西:
1. **明星陣容**:名字、外觀、性格組合(12 選 2 = 66 種)、技能、口頭禪、喜歡的話題、夢想媒體全隨機。
2. **人際關係**:誰跟誰是朋友/對手每局不同,會因為你的決定改變。
3. **趨勢序列**:演算法和話題每局隨機。
4. **事件**:25 種事件隨機抽(另外還有「想跳槽」),大部分有 2~4 個選擇,少數是好消息/突發狀況直接發生。
5. **機會**:媒體 × 話題 × 標題模板組合,每週隨機。
6. **結局**:5 種,看你的經營方式。

真正的取捨:給最強的 vs 給沒機會的、接案賺錢 vs 練習 vs 休息、追這週趨勢 vs 為下週準備、花錢升級公司 vs 升設施 vs 試鏡新人、答應心願 vs 顧大局。

## 9. 技術

- `games/aistar/engine.js`:**純邏輯、不碰 DOM**,固定種子的亂數(存在存檔裡)。Node 可以直接跑 → 自動玩家 `tools/aistar_autoplay.mjs`。
- `games/aistar/data.js`:媒體、性格、話題、事件、數值。
- `games/aistar/lines.js`:對話模板(情境 × 性格,大量變化),佔位字 `{op}{rival}{friend}{skill}{topic}`。
- `games/aistar/main.js`:畫面(上:攝影棚像素場景,明星走到各自的位置,頭上冒泡泡;下:機會/明星/公司/訊息分頁)。
- `games/aistar/store.js`:照溫泉旅館的做法 —— localStorage + IndexedDB 雙重保存、每 15 秒自動存、存檔碼備份/輸入。
- `shared/pixelkit/studio.js`:攝影棚地板/牆、攝影機、補光燈、綠幕、麥克風、Podcast 桌、直播桌、練舞鏡、舞台、沙發、大螢幕、獎盃櫃、頭上配件。畫風跟 `furniture.js` 一致。
- 音效 `shared/kit.js`、配樂 `shared/music.js`。**不依賴還在改的 `shared/tycoon/`**。
