# AI 明星養成 v2 — 虛擬辦公大樓(設計)

> 2026-10-25,SS 試玩 v1 後的回饋:
> 1. 每週的結算報告太大 → **已改成底部小卡(已上線)**
> 2. 想看明星**工作的小動畫**
> 3. 體力除了休息要有**別的回復方法**
> 4. 排程太單一,**沒有時間讓明星休息**
> 5. 要像溫泉旅館一樣有**虛擬 Office**:訓練、吃飯的地方;像韓國娛樂公司,有**練習生、女團製作**;可以在辦公室**跟明星互動**;每人有**一個大目標**(演員/歌手/全能/模特);有**自家製作部、SNS 管理部、發掘明星、請普通員工**(像《明星志願》)
> 6. 公司可以擴展,看到他們在動,**變成高樓、有不同樓層和區域**
> 7. 之後可以**跟其他公司合作**,一開始不用有其他公司的 Office

v1 的核心(明星有個性、會搶機會、沒選上會反應、趨勢每週變)全部保留。v2 改的是「畫面」和「時間」:從「卡片清單」變成「一棟會長高的公司大樓,一週七天在裡面動」。

---

## 1. 畫面:側面剖開的公司大樓

像《開羅》或 Tiny Tower 那種**側面剖面**:一層一長條,從 1F 往上疊。手機直式剛好適合 —— 上下滑動看整棟樓。

```
 ┌──────────────────────────┐ 屋頂(之後:慶功派對)
 │ 5F  🎤 錄音室     ♪ ♪     │ ← 有人在唱歌,冒音符
 ├──────────────────────────┤
 │ 4F  🍱 員工餐廳   🍜 🍜    │ ← 中午大家下來吃飯,回體力
 ├──────────────────────────┤  電
 │ 3F  💃 舞蹈室    🕺 💦    │  梯
 ├──────────────────────────┤  ↕
 │ 2F  🛏 宿舍       zzz      │ ← 晚上回來睡覺
 ├──────────────────────────┤
 │ 1F  🏢 大廳/櫃台  🧍       │ ← 來試鏡的人、合作公司的人從這裡進來
 └──────────────────────────┘
```

- 每層 = 一個「區域」,寬 10 格、高 3 格(後牆 + 地板),家具用 pixelkit 程式畫,跟現在的攝影棚同一套畫風。
- 右邊是電梯,明星搭電梯上下樓(會走過去、等一下、出現在別層)。
- **蓋新樓層**:花錢在頂樓上面加一層,選它是什麼區域;每層可以升級 Lv1~3(家具變多、效果變大、能容納的人變多)。公司等級改成看「樓層數」,大樓就是成長的證明。
- 點樓層 → 看這層的人和效果、升級;點明星 → 跟他互動(見第 6 節)。

| 區域 | 用途 | 解鎖 |
|---|---|---|
| 🏢 大廳(1F 固定) | 櫃台員工、訪客進出(試鏡新人、合作公司代表) | 一開始 |
| 🛏 宿舍 | 晚上睡覺回體力;等級越高回越多、住越多人 | 一開始 |

| 🍱 員工餐廳 | **每天中午吃飯回體力**;請廚師、升級 → 餐點更好 | 一開始 |

## 2. 時間:每週排七天的行程

這是解決「排程太單一、沒時間休息」的核心。

- 一回合還是一週,但每位明星有一張**七天行程表**(一 ~ 日),每天一格。
- 一格可以是:🎬 工作(機會)/ 💃🎤🎭🎙 練習 / 🛏 休息 / 🔴 自己直播 / 🎉 放假(出去玩:心情大回復)。
- **機會改成「要幾天」**:短影音 1 天、直播 1 天、Podcast 1 天、繪本配音 2 天、雙人企劃 2 天、廣告 2 天、AI 短劇 4 天、選秀 3 天、虛擬演唱會 2 週各 4 天。所以一個人一週可以接兩、三個小案子,中間還能排休息。
- 選人之後,工作天自動排進他的行程;其他天預設「練專長、週日休息」,小孩點格子就能換(一格一格點,循環切換)。
- 有「🪄 自動排」按鈕:幫每個人排好(工作 → 練習 → 週日休息,體力低的多休息)。
- **連續工作太多天**:體力掉光 → 演出變差、心情變差、可能感冒;行程表上會用紅色提醒「太累了!」。

### 一週怎麼播

排好按「▶ 開始這週」→ 大樓裡七天一天一天播(每天約 4 秒,可以 ⏩ 2 倍、4 倍或直接跳到週末):

- 早上:各自去行程的樓層(練習室、攝影棚、或出門工作 —— 走到 1F 大廳出門,傍晚回來)
- **中午:全部人到員工餐廳吃飯**(+體力)
- 下午:回去繼續
- 晚上:回宿舍睡覺(+體力),或去休息室放鬆
- 每天的事件、閒聊泡泡、搶機會的訊息照常冒出來
- 播完 → 底部小卡週報(已做好的那個)

## 3. 工作小動畫

`character.js` 不改,所以動畫靠:換格(待機/走路)、上下跳、左右翻、加道具、加粒子。

| 在做什麼 | 動畫 |
|---|---|
| 練舞 / 短影音 | 左右轉身 + 小跳,冒 💦,鏡子前 |
| 練唱 / 錄音 | 拿麥克風,頭上飄 ♪ 音符 |
| 演技 / 拍短劇 | 打板 🎬 閃一下,攝影機紅燈閃 |
| 口才 / Podcast | 坐在桌前,嘴邊冒「…」小框 |
| 直播 | 對著補光燈,飄 ♥ |
| 吃飯 | 坐在餐桌,碗冒熱氣 |
| 睡覺 | 躺在床上(畫在床上的半身),飄 zzz |
| 休息室 | 坐按摩椅/泡腳,飄 ✨ |
| 員工打字 | 坐電腦前,螢幕閃 |

## 4. 體力的回復方法

| 方法 | 回多少 | 備註 |

| 🛏 排一整天休息 | +30 | 跟 v1 一樣 |
| 🎉 放假出去玩 | +25,心情 +15 | |
| 🧖 休息室(晚上有空就去) | +8,心情 +5 | |

| 🤝 跟好朋友一起吃飯 | 心情 +3 | 自動發生 |

## 5. 明星的大目標、練習生、團體(第 2~3 階段)

- **大目標**:每位明星有一個:🎤 歌手 / 🎭 演員 / 💃 舞者 / 🎙 綜藝人 / 📸 模特 / 🌟 全能偶像。目標決定他最想搶什麼、最後的「個人結局」(結局畫面每人一句:「我真的變成歌手了!」或「我還在努力」)。每個目標有 3 個里程碑(例:歌手 = 發第一首歌 → 上音樂節目拿第一 → 開個人演唱會)。
- **新技能 💄 魅力**:模特、廣告、代言看它;在造型室練。
- **練習生**:新人先當練習生,住宿舍、每天練習,只能接小案子。每 4 週一次**月末評鑑**(像韓國公司),分數夠就可以**出道**(個人出道或進團體)。
- **🔭 星探部**:每週發掘 1~2 位新人(看得到性格和潛力,技能要練了才知道),簽約成練習生。試鏡會保留。
- **👯 團體企劃(女團/男團)**:選 3~5 人組團,取團名(隨機產生器 + 可以改)、選風格(可愛/帥氣/清新/搞笑)。團體有自己的粉絲和**默契**(看成員之間的關係)。製作部做專輯 → **回歸** → 音樂節目打歌 → 年底音樂頒獎。成員吵架會影響默契,這就是「搶 C 位」的劇情來源。

## 6. 在辦公室跟明星互動

點大樓裡的明星 → 小選單:

- 💬 聊天:他會照性格跟你講心事、心願、對別人的看法(對話模板)
- 🍪 送點心:體力 +10(一天一次)
- 👏 鼓勵:心情 +,跟你的**信任**+(信任高的人不容易跳槽)
- 📅 看行程、📋 看資料

另外大樓裡會自己發生小場景:好朋友一起吃飯、對手半夜還在練舞、練習生在走廊互相加油。

## 7. 部門與員工(第 2~3 階段)

- **請普通員工**(在大廳請,有薪水、會升級、在大樓裡走動):
  🧑‍💼 經紀人(酬勞 +、自動幫你談案子)、🏋 訓練師(練習效果 +,分舞蹈/歌唱/演技)、🧑‍🍳 廚師(餐廳)、📱 小編(SNS 部門)、🔭 星探(星探部)、🎛 製作人(製作部)、💄 造型師(造型室)
- **🎛 自家製作部**:不只接別人的案子,也可以自己做 —— 自家 AI 短劇、專輯、綜藝節目。要花錢、花好幾週、要攝影棚,但做好了是長期收入(每週有播放分潤)。
- **📱 SNS 部門**:每週選一個社群策略(日常 Vlog / 挑戰 / 幕後花絮 / 粉絲問答),每位明星被動漲粉;遇到假影片、壞留言事件處理得更好。

## 8. 跟其他公司合作(第 4 階段)

- 一開始只有「別家公司」在排行榜上(現在就有)。
- 蓋了🤝會議室之後,別家公司會來**談合作**:聯名企劃(你的明星 + 他們的明星,粉絲互相流動)、借將(把你的明星借出去賺錢,但他不在一週)、聯合演唱會。
- 合作公司的人會從 1F 大廳走進來開會。
- 之後再發展:可以去參觀別家公司的大樓(只能看)。
